# 🚀 Overview

AI Chatbot is a scalable conversational AI platform built using Python, Flask, and OpenAI GPT models.  
It supports multi-turn conversations, persistent storage, user management, and API-driven integrations for modern AI applications.

This project is designed with production-ready architecture principles including:
- Context-aware conversations
- Persistent memory handling
- API-first design
- Token monitoring
- Database flexibility
- Extensible chatbot workflows

---

# ✨ Core Features

## 🧠 AI & Conversation Features

- OpenAI GPT-4 powered chatbot responses
- Multi-turn contextual conversations
- Intelligent conversation memory handling
- Adjustable response creativity using temperature controls
- Persistent conversation storage

---

## 🔐 User & Session Management

- User creation & management system
- Conversation history tracking
- Conversation reset & close support
- Timeout configuration handling

---

## ⚡ API & Backend Features

- RESTful API architecture
- Flask-powered lightweight backend
- CORS enabled for frontend integrations
- SQLite & PostgreSQL support
- Token usage tracking & monitoring
